Delivery Logic

Core business rule of this platform
⚡ Express Delivery
✅ Defined at product level by admin
✅ Date picker shown on product page (Today / Tomorrow / Schedule)
✅ Selected date stored in order_items.delivery_date
✅ Fulfilled by local/express courier partner
✅ Admin adds tracking URL after shipping
Suitable for: Flowers, cakes, chocolates — perishables & time-sensitive
📦 Courier Delivery
✅ No date picker — automatic 7 working day ETA
✅ ETA calculated: order_date + 7 working days
✅ Shown on product page & checkout as message
✅ Via India Post / Delhivery / Blue Dart etc.
✅ Tracking code + URL added by admin post-shipping
Suitable for: Custom/personalised items, printed products, non-perishables
Order Tracking Logic (No custom API needed)
📦
Order Placed
Admin sees in dashboard
🚚
Admin Ships
Gets tracking code from courier
🔗
Enters in Admin
tracking_url + tracking_code saved
👤
Customer Tracks
"Track Order" → opens courier site directly
